# Hospital Management System 🏥

A professional Hospital Management System developed using **Python** and **Django** to manage hospital operations digitally. This project helps hospitals efficiently manage doctors, patients, appointments, and queries through an easy-to-use web interface.

---

# 🚀 Features

## 👨‍⚕️ Doctor Management
- Add Doctor
- View Doctor Details
- Edit Doctor Information

## 🧑‍🤝‍🧑 Patient Management
- Add Patient
- View Patient Details
- Edit Patient Information

## 📅 Appointment Management
- Book Appointments
- View Appointments

## 📩 Query Management
- Read User Queries
- Unread Query Section

## 🔐 Authentication System
- Login Page
- Admin Navigation Panel

## 🎨 Responsive User Interface
- Bootstrap-based frontend design
- Easy navigation and clean layout
